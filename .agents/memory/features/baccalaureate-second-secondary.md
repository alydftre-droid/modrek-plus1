name: Baccalaureate system (second secondary)
description: الصف الثاني الثانوي (عام) بلا شعبة — يُسجّل تلقائيًا كعلمي ويظهر باسم "بكالوريا"
type: feature
---

الصف الثاني الثانوي في التعليم العام أصبح نظام **بكالوريا** ولا يوجد فيه علمي/أدبي.

- عند التسجيل: لا تظهر خطوة الشعبة نهائيًا؛ يُحفظ `profiles.section = "علمي"`
  تلقائيًا (`BACCALAUREATE_SECTION` في `src/lib/educationSection.ts`) ويُوجَّه
  الطالب مباشرة إلى حسابه.
- سبب تخزين "علمي": كل منطق المواد/المحتوى/المعلمين/الحزم يبقى كما هو،
  والطالب يرى نفس مواد القسم العلمي.
- العرض فقط: `formatSectionLabelForScope()` يعيد "بكالوريا" بدل "علمي"
  لأي (secondary + second + عام).
- الأزهر يحتفظ بنظام علمي/أدبي لكل الصفوف — لا تطبق البكالوريا عليه.
- الطلاب القدامى في الثاني الثانوي (عام) يتم إصلاح شعبتهم تلقائيًا عند فتح
  لوحة الطالب.
