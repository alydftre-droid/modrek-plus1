# تقرير Bunny CDN Redirect — قبل وبعد

التاريخ: 2026-08-03 · الدالة: `bunny-storage` (الإصدار `teacher-media-legacy-v5-2026-07-31`)

## ما تم تنفيذه

بعد نجاح فحص الصلاحية (بدون أي تغيير في قواعد الوصول)، تُصدر الدالة الآن استجابة
`302` إلى رابط Bunny CDN بدل تمرير بايتات الملف عبر دالة الحافة:

- التوقيع: Bunny Token Authentication الأساسي
  `token = base64url(sha256(tokenKey + "/" + path + expires))` وصلاحية 60 دقيقة.
- التحويل يُطبَّق فقط على طلبات المتصفح المباشرة (`Sec-Fetch-Dest` = image / video /
  audio / iframe / document / embed / object). طلبات `fetch/XHR` (تحميل PDF كـ Blob،
  خط أنابيب الذكاء الاصطناعي) تبقى على المسار القديم تمامًا لأن CORS مطلوب فيها.
- مستثنى دائمًا: فيديو تعريف المعلم (`content/teacher-intros/*`) لأنه يُستبدل في مكانه.
- منفذ التعطيل الفوري: `?noredirect=1` لأي طلب، أو المفتاح العام `BUNNY_CDN_REDIRECT=off`.

## مفاتيح التحكم

| المفتاح | القيمة | الأثر |
|---|---|---|
| `BUNNY_CDN_TOKEN_KEY` | مفتاح Token Auth من Pull Zone | **يفعّل التحويل** بروابط موقعة قصيرة العمر |
| `BUNNY_CDN_REDIRECT` | `off` | إرجاع فوري للسلوك القديم (تمرير كامل) |
| `BUNNY_CDN_REDIRECT` | `on` | تفعيل قسري بروابط غير موقعة (غير موصى به) |

الوضع الحالي: `BUNNY_CDN_TOKEN_KEY` غير مُضاف، لذلك التحويل **غير مُفعّل** والمنصة تعمل
بسلوكها السابق حرفيًا. بمجرد إضافة المفتاح يعمل التحويل بدون أي نشر جديد.

## الأثر المتوقع على Egress والأداء

| المقياس | قبل | بعد (مع تفعيل المفتاح) |
|---|---|---|
| بايتات الفيديو/الصور عبر دالة الحافة | 100% | ~0% (تخرج من Bunny CDN) |
| Egress من Supabase للوسائط | ~4.5 GB / 5 GB | تقديري 0.3–0.6 GB (انخفاض 85–93%) |
| زمن أول بايت للفيديو | مرور مزدوج (CDN → دالة → متصفح) | مرور واحد من أقرب حد CDN (أسرع بـ 2–4×) |
| استدعاءات الدالة | استدعاء + بث كامل لكل نطاق بايت | استدعاء واحد قصير جدًا لكل ملف ثم CDN مباشرة |
| ملفات PDF عبر `fetch` | كما هي | كما هي (لا تغيير مقصود للحفاظ على CORS) |

## نتائج اختبار الانحدار

- `deno test supabase/functions/bunny-storage/` → 6/6 ناجحة (منها 3 اختبارات جديدة
  تتحقق من ترتيب فحص الصلاحية قبل التحويل، واستثناء الفيديو التعريفي، وصحة التوقيع).
- `bunx tsgo --noEmit` → بدون أخطاء. `bun run build` → ناجح.
- نشر الدالة على الإنتاج → ناجح، والطلب بدون مصادقة ما زال يرجع `401 Unauthorized`
  (لم تُضعف الحمايات).
- فحص متصفح على `/`، `/auth`، `/delete-account`، `/about` → 0 أخطاء Console.
- الدفع، الدخول، المكتبة، المساعد الذكي، الرفع: لم يُلمس أي منها في الكود؛ مسار
  `fetch` الخاص بها يسلك نفس الفرع القديم بالكامل.

## الخطوة المتبقية لتفعيل الوفر

من لوحة Bunny → Pull Zone → Security → Token Authentication، انسخ
`Token Authentication Key` وأرسله لي لإضافته كسر `BUNNY_CDN_TOKEN_KEY`.
عندها أقيس Egress قبل/بعد فعليًا لمدة 24 ساعة، وإن ظهرت أي مشكلة أعيد الوضع فورًا
بضبط `BUNNY_CDN_REDIRECT=off`.
