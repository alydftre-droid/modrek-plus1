# استبدال "الأحياء" بـ "التاريخ" — الصف الثاني الثانوي / علمي (عام + أزهري)

## ما وجدته فعليًا في قاعدة البيانات (فحص كامل قبل أي تعديل)

- جدول المواد `subjects` أعمدته: `name, stage, grade, section, category, is_active, shared_subject_id`.
- **لا يوجد جدول أو عمود للسنة الدراسية (Academic Year) في المنصة أصلًا.** المنهج الحالي = المنهج المعمول به الآن (2026/2027). لذلك تحديد المادة يتم عبر: `stage + grade + section + category + name`، ونوع التعليم (عام/أزهري) يُحسب من التصنيف ومن `education_type` في التكليفات والمحتوى — وهذا ما سأعتمد عليه بدل الاعتماد على الاسم فقط.
- الصف الثاني الثانوي/علمي فيه صف واحد فقط لمادة الأحياء:
  `b947c94a-…` (`science`, `secondary`, `second`, `scientific`, نشطة). هذا الصف مشترك بين التعليم العام والأزهري (لا يوجد صف منفصل لكل نوع تعليم).
- **لا توجد أي بيانات مرتبطة بهذا الصف**: 0 محتوى، 0 امتحانات، 0 اشتراكات، 0 طلبات اشتراك، 0 مجموعات، 0 كتب مكتبة، 0 دروس AI، 0 باقات. أي لا يوجد Foreign Key سينكسر.
- توجد تكليفات معلم واحدة `أحياء / secondary / الصف الثاني الثانوي` (لن تُحذف).
- صفوف الأحياء الأخرى (أول ثانوي، ثالث ثانوي، الإعدادي، الأدبي) لن تُلمس.

## التعديل في قاعدة البيانات (Migration واحدة قابلة للتراجع)

1. إضافة مادة `التاريخ` كصف حقيقي جديد:
   `name='التاريخ', category='science', stage='secondary', grade='second', section='scientific', is_active=true`
   — وضعها في تصنيف `science` (البوكس العلمي) يجعلها تظهر في نفس مكان الأحياء تمامًا لطلاب علمي (عام + أزهري)، وتعمل مع المعلمين والمجموعات والاشتراكات والمحتوى والامتحانات والبحث بدون أي حل مؤقت.
2. إيقاف مادة الأحياء **لهذا التكوين فقط** عبر Soft Delete: `is_active=false` للصف `b947c94a-…` فقط (بشرط صريح على stage+grade+section+category+name). لا حذف نهائي، ولا `UPDATE … WHERE name='الأحياء'` عام.
3. لا حذف أو تعديل لأي حساب طالب/معلم أو اشتراك أو درجة أو تقدم أو سجل مالي.

## التعديل في منطق الواجهة (المنطق الحالي فيه قوائم أسماء ثابتة تتجاهل الصف)

- `src/lib/educationSection.ts`: تحويل قائمة المواد العلمية إلى دالة تعتمد على `stage + grade + section` بدل قائمة ثابتة، فترجع للثاني الثانوي علمي: الفيزياء، الكيمياء، **التاريخ** (+ الرياضيات لغير المتخصص) بدل الأحياء.
- `src/lib/studentCategories.ts`: إضافة بطاقة مادة "التاريخ" داخل البوكس العلمي، واستخدام الدالة الجديدة في اختيارات الباقات والمواد.
- `src/pages/student/CategorySubjectsPage.tsx`: إظهار "التاريخ" بأيقونتها داخل علمي للثاني الثانوي، وإخفاء الأحياء لهذا التكوين.
- `src/lib/teacherSubjectUtils.ts` + `src/lib/teacherFiltering.ts`: السماح بربط اختيار المعلم "تاريخ" بالثاني الثانوي علمي (تصنيف science) بجانب الأدبي، بدون تداخل مع صفوف أو شُعب أخرى.
- `src/lib/libraryTaxonomy.ts`: مزامنة نفس القاعدة في تصنيف المكتبة.
- بقية الصفوف والشُعب والتصنيفات تعمل كما هي بدون تغيير.

## الاختبارات بعد التنفيذ

- طالب عام + ثاني ثانوي علمي → التاريخ تظهر، الأحياء لا تظهر.
- طالب أزهري + ثاني ثانوي علمي → نفس النتيجة.
- أول ثانوي / ثالث ثانوي / أدبي / إعدادي → لا تغيير (فحص استعلامات فعلية).
- معلم مرتبط بالتاريخ ثاني ثانوي علمي يظهر صحيحًا، ومعلم التاريخ في صف آخر لا يظهر هنا.
- بحث شامل في الكود عن أي مكان يعرض "الأحياء" في هذا التكوين.

## ملاحظة مهمة قبل الموافقة

لا يمكن ربط التعديل بالسنة الدراسية 2026/2027 داخل قاعدة البيانات لأن المنصة لا تخزن السنة الدراسية إطلاقًا. التعديل سيسري على المنهج الحالي (وهو 2026/2027)، والبيانات القديمة محفوظة كما هي لأن صف الأحياء يبقى موجودًا (غير نشط) ولا توجد بيانات مرتبطة به.
