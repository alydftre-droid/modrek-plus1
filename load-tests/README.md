# Load Testing – Modrek Plus

اختبارات الضغط تعمل خارج بيئة Lovable. تم تجهيز سيناريو k6 جاهز للتشغيل.

## المتطلبات
- تثبيت k6: https://k6.io/docs/get-started/installation/
- بيئة مستقلة (لا تُشغّل ضد قاعدة الإنتاج مباشرة إن أمكن، استخدم بيئة staging).

## التشغيل
```bash
BASE_URL=https://modrek-plus.lovable.app k6 run load-tests/k6-baseline.js
```

## السيناريو
- **smoke**: مستخدم واحد لمدة دقيقة (تحقق سلامة).
- **ramp**: تصاعد من 0 إلى 200 مستخدم متزامن خلال 5 دقائق، ثبات 5 دقائق، ثم تهدئة.

## المعايير (Thresholds)
- نسبة الفشل < 2%.
- P95 لزمن الاستجابة < 1500ms.
- P99 < 3000ms.

## توسيع السيناريوهات
لإضافة سيناريوهات لتسجيل الدخول أو استدعاء Edge Functions، وسّع الملف بتوكن اختبار عبر متغير بيئة `TEST_JWT`، ثم استخدمه في الترويسة `Authorization: Bearer ${TEST_JWT}`.

⚠️ لا تخزّن توكنات حقيقية داخل المستودع.
